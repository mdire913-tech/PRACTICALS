AIM: Case Study: PaaS (Google App Engine, Heroku)

PAAS- Platform as a service

Platform as a Service (PaaS) is a cloud service model that provides a ready-made platform
where developers can build, test, deploy, and manage applications without worrying about
servers, storage, or networking.


Google App Engine
Google App Engine is a fully managed Platform as a Service (PaaS) offering from Google Cloud
Platform that enables developers to build, deploy, and scale applications without managing
infrastructure. It automatically scales applications up or down based on demand while providing
a secure and reliable runtime environment.
   •     Google App Engine is a scalable runtime environment primarily used for hosting web and
         mobile applications.
   •     Provides a secure execution environment along with built-in services for developing
         high-performance applications.
Google App Engine Working
Steps:
   1. The developer writes the application code (Python, Java, Node.js, etc.).
   2. The application is uploaded to Google App Engine.
   3. Google automatically provides the required servers, operating system, and runtime
      environment.
   4. The application is hosted on Google's cloud and becomes available to users over the
      internet.
   5. If more users access the application, Google automatically increases resources.
   6. If traffic decreases, resources are reduced automatically.
   7. Google handles server maintenance, updates, security, and monitoring.
   8. The developer only focuses on improving the application.
Features of Google App Engine (GAE)
   1. Automatic Scaling
   •     Automatically increases or decreases resources based on user traffic.

2. No Server Management
   •   Developers do not need to manage servers or operating systems.
   3. Multiple Language Support
   •   Supports languages like Python, Java, Go, Node.js, PHP, and Ruby.
   4. Load Balancing
   •   Automatically distributes user requests across multiple servers for better performance.



Heroku
Heroku is a Platform as a Service (PaaS) that allows developers to build, deploy, run, and
manage applications without managing servers or infrastructure.


How Heroku Works
   1. The developer writes the application code.
   2. The code is uploaded to Heroku (using Git or GitHub).
   3. Heroku automatically builds and deploys the application.
   4. Heroku manages the servers, operating system, and runtime.
   5. Users access the application through the internet.
   6. Heroku automatically scales the application when traffic increases.


Advantages of Heroku
1. Easy to Use
   •   Simple interface for beginners.
   •   Quick application deployment.
2. No Server Management
   •   Developers do not manage servers or operating systems.
   •   Heroku handles maintenance and updates.
3. Automatic Scaling
   •   Automatically adjusts resources based on traffic.
   •   Improves application performance during high demand.

4. Supports Multiple Languages
   •   Supports Java, Python, Node.js, Ruby, PHP, etc.
   •   Developers can use their preferred programming language.


Disadvantages of Heroku
1. Higher Cost
   •   Can become expensive as the application grows.
   •   Advanced features require paid plans.
2. Limited Infrastructure Control
   •   Developers cannot fully control servers.
   •   Custom server configurations are limited.
3. Vendor Lock-in
   •   Applications depend on the Heroku platform.
   •   Migrating to another platform may require changes.
4. Resource Limits
   •   Free and low-cost plans have limited resources.
   •   Large applications may need higher-tier plans.
