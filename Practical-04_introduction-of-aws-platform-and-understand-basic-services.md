Introduction to AWS

AWS (Amazon Web Services) is a cloud computing platform provided by Amazon. It offers
different cloud services for computing, storage, databases, networking, security, and many other
requirements.

Instead of purchasing and maintaining physical servers, we can use AWS resources over the
Internet and pay according to usage.

5 Most Important AWS Services

1. Amazon EC2 – Compute

EC2 (Elastic Compute Cloud) provides virtual servers in the AWS cloud.

Why do we use it?

    •   To run websites and applications.

    •   To host software on a virtual server.

    •   To install and run operating systems and other software.

Example: If a company wants to host its website, it can create an EC2 instance and run the
website on it.



2. Amazon S3 – Storage

S3 (Simple Storage Service) is used to store files and data in the cloud.

Why do we use it?

    •   To store images, videos, documents, and backups.

    •   To access stored files from anywhere.

    •   It provides highly durable storage.

Example: A college can store student documents, certificates, and images in an S3 bucket.



3. IAM – Security & Access Management

IAM (Identity and Access Management) is used to manage users, permissions, and access to
AWS resources.

Why do we use it?

    •   To create AWS users.

Example: An administrator can give a developer permission to use EC2 but prevent them from

4. Amazon VPC – Networking

VPC (Virtual Private Cloud) allows us to create a private and controlled network inside AWS.

Why do we use it?

   •   To organize AWS resources into a network.

   •   To control network traffic.

   •   To create public and private subnets.

   •   To improve application security.

Example: A company can keep its web server in a public subnet and its database in a private
subnet.



5. Amazon RDS – Database

RDS (Relational Database Service) is a managed service for running relational databases.

Why do we use it?

   •   To store structured application data.

   •   AWS manages many database administration tasks.

   •   It supports databases such as MySQL, PostgreSQL, and others.

Example: An online shopping website can use RDS to store customer, product, and order
information.

Easy way to remember

EC2 → Server
S3 → Storage
IAM → Security
VPC → Network
RDS → Database
