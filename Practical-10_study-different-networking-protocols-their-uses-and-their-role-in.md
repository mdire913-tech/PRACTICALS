Practical 10



AIM: To study different networking protocols, their uses, and their role in computer networking.

What is a Network Protocol?

   •   A protocol is a set of rules used for communication between devices over a network.
   •   It defines how data is transmitted, received, and understood by network devices.
   •   Different protocols are used for different networking purposes.

1. HTTP – HyperText Transfer Protocol

   •   Used to access and transfer web pages.
   •   It is mainly used for communication between a web browser and web server.
   •   Port Number: 80
   •   Example: Opening a normal HTTP website.

2. HTTPS – HyperText Transfer Protocol Secure

   •   Secure version of HTTP.
   •   Encrypts data exchanged between the browser and web server.
   •   Port Number: 443
   •   Example: Online banking and shopping websites.

3. FTP – File Transfer Protocol

   •   Used to transfer files between computers over a network.
   •   Supports uploading and downloading files.
   •   Port Number: 21
   •   Example: Uploading website files to a server.

4. SFTP – SSH File Transfer Protocol

   •   Used for secure file transfer.
   •   Transfers files through an SSH connection.
   •   Port Number: 22
   •   Example: Securely transferring files to a Linux server.

5. SMTP – Simple Mail Transfer Protocol

   •   Used for sending emails.
   •   Transfers email from a client to a mail server and between mail servers.
   •   Port Number: 25
   •   Example: Sending an email.

6. POP3 – Post Office Protocol Version 3

   •   Used to receive emails from a mail server.
   •   Usually downloads emails to the user's device.
   •   Port Number: 110
   •   Example: Downloading emails from a mail server.

7. IMAP – Internet Message Access Protocol

•   Used to access and manage emails stored on a mail server.
   •   Keeps emails synchronized across multiple devices.
   •   Port Number: 143
   •   Example: Accessing the same Gmail account from mobile and computer.

8. DNS – Domain Name System

   •   Converts domain names into IP addresses.
   •   Helps users access websites using easy-to-remember names.
   •   Port Number: 53
   •   Example: google.com → IP address

9. DHCP – Dynamic Host Configuration Protocol

   •   Automatically assigns IP addresses to devices.
   •   It can also provide subnet mask, gateway, and DNS information.
   •   Port Number: 67/68
   •   Example: A laptop automatically getting an IP address after connecting to Wi-Fi.

10. SSH – Secure Shell

   •   Used for secure remote access to another computer or server.
   •   Data is encrypted during communication.
   •   Port Number: 22
   •   Example: Remotely managing a Linux server.

11. Telnet – Teletype Network

   •   Used for remote login and accessing another computer.
   •   It does not encrypt communication.
   •   Port Number: 23
   •   It is mainly used today for testing or legacy systems.

12. ICMP – Internet Control Message Protocol

   •   Used for network error reporting and diagnostics.
   •   Helps check whether a device is reachable.
   •   Example: ping command uses ICMP.

14. TCP – Transmission Control Protocol

   •   Provides reliable and ordered delivery of data.
   •   Establishes a connection before transmitting data.
   •   Checks whether data has been delivered correctly.
   •   Example: Web browsing, email, and file transfer.

15. UDP – User Datagram Protocol

   •   Provides fast, connectionless communication.
   •   Does not guarantee delivery or order of packets.
   •   Has lower overhead than TCP.
   •   Example: Online gaming, live streaming, and some DNS traffic.
